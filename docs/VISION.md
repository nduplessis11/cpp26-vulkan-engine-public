# Vision

Build a comprehensible native C++ engine by learning every important boundary rather than assembling opaque libraries.

The engine should eventually support modern 3D scenes, modern 2D scenes, native Windows and Linux platform layers, an editor, scene serialization, asset cooking, asynchronous loading, audio, and a deliberately scoped physics system, with repeatable tests, validation, profiling, CI, and packaging.

It is not trying to beat Unreal, Unity, Godot, commercial physics middleware, or production media codecs. Success means the learner can explain, debug, extend, and measure the whole system.
